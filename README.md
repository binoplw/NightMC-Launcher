## 📥 Установка

### Способ 1: Установщик (рекомендуется)

1. Скачайте последнюю версию из [Releases](https://github.com/binoplw/NightMC-Launcher/releases)
2. Запустите `NightMC-Setup-5.0.0.exe`
3. Следуйте инструкциям установщика
4. Готово! Запускайте лаунчер с рабочего стола

### Способ 2: Портативная версия

1. Скачайте портативную версию из [Releases](https://github.com/binoplw/NightMC-Launcher/releases)
2. Распакуйте архив в любую папку
3. Запустите `NightMC.exe`

### Способ 3: Для разработчиков

```bash
# Клонируйте репозиторий
git clone https://github.com/binoplw/NightMC-Launcher.git
cd NightMC-Launcher

# Установите зависимости
npm install

# Запустите
npm start
